# Polyra learner app (prototype)

Scope: the learner's daily loop on a phone: home, word card, exercise, answer feedback, session end,
settings. Visitor mode: Operate.

Audience and task: Persian-speaking adults learning French or German; press Start, work through a
15-minute mixed session, see honest progress. Constraints: RTL Persian UI that can switch to LTR,
both themes designed, reduced motion respected, no emoji, no gamification devices.

Memorable moment: the holographic foil on the Start card, and the level seal at session end.

Unresolved: owner has not yet locked this direction (alternate: Tehran modernism). Built on the
recommended option while the choice is open.

## Direction contract

THESIS: Progress as an earned credential. The app is a quiet, precisely engraved document of the
learner's French or German, not a game. Refuses the cartoon-gamified arrangement (mascot, bright
tiles, confetti, XP).

OWN-WORLD: Security paper ground (cool grey-green), deep navy intaglio ink, engraving green for fine
guilloche lines, seal red only for streak and errors, holographic foil as the single liquid material.
Markazi Text for Persian display, Vazirmatn for Persian UI text, Bodoni Moda for the target language.
Hairlines at half a pixel, double rules, round seals; corners modest.

STORY: The learner sees today's session and their level at a glance, presses Start, meets each word
in an elegant dictionary-like card with sound, answers, and ends the session with a seal that marks
what was earned.

FIRST VIEWPORT: Top bar (language seal, streak, freeze, settings). Navy Start card full width: Persian
"شروع" large on the start side, session summary above it, holographic foil disc under an engraved
rosette on the end side. Under it the short-session link and plan line. Four skill medallions in one
ruled row (icon, name, level, progress). Links list below.

FORM: Security print and credentials, first on the ordered list (impeccable's pick). The roll ran
degraded (online service unreachable, local fallback only) and assigned candidate 3, Tehran modernism;
both went to the owner on the decision board. seed: none (unavailable)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
