# گذاشتن نسخه آزمایشی روی رانفلر

این راهنما برای صاحب محصول است. هر جا گیر کردی، عکس صفحه را بفرست.

## چه چیزی ساخته می‌شود

- یک **پایگاه داده** (PostgreSQL نسخه ۱۷) که همه محتوا و حساب‌ها در آن است.
- یک **برنامه** (سرویس داکر) که از شاخه `claude/project-thread-w5dehc` در گیت‌هاب ساخته می‌شود. هر بار
  Claude کد تازه بفرستد، رانفلر خودش برنامه را دوباره می‌سازد.
- یک **دیسک** برای فایل‌های صوتی، تا با هر بار ساخت دوباره پاک نشوند.

## مرحله ۱: پایگاه داده

1. در پروژه رانفلر، یک سرویس پایگاه داده **PostgreSQL** با نسخه **17** بساز. نامش را `polyra-db` بگذار.
2. بعد از ساخته شدن، در صفحه همان سرویس این چهار چیز را پیدا کن و برای مرحله ۳ نگه دار:
   نام کاربری، رمز، نام پایگاه داده، و آدرس داخلی (چیزی شبیه `polyra-db-service`).

## مرحله ۲: برنامه

1. یک سرویس تازه از نوع **Docker** بساز و آن را به گیت‌هاب وصل کن.
2. مخزن `amahmoodi1379-glitch/polyra` و شاخه `claude/project-thread-w5dehc` را انتخاب کن.
3. فایل ساخت همان `Dockerfile` اصلی پوشه است (چیزی را عوض نکن).
4. پورت برنامه: **3000**.
5. حجم کم کافی است؛ اگر رانفلر پرسید، دست‌کم ۱ گیگ حافظه (RAM) بده.

## مرحله ۳: متغیرها

در بخش متغیرهای محیطی (Environment) همان سرویس برنامه، این‌ها را بگذار:

| نام | مقدار |
| --- | --- |
| `DATABASE_URL` | `postgresql://نام‌کاربری:رمز@آدرس‌داخلی:5432/نام‌پایگاه` (از مرحله ۱) |
| `AUTH_SECRET` | یک متن طولانی تصادفی (دست‌کم ۴۰ حرف و عدد) |
| `PHONE_HASH_SECRET` | یک متن طولانی تصادفی دیگر، فرق با بالایی |
| `SITE_PASSWORD` | رمزی که خودت برای باز کردن نسخه آزمایشی می‌خواهی |
| `SEED_ADMIN_PHONE` | شماره موبایل خودت؛ با این شماره ادمین می‌شوی |
| `SMS_PROVIDER` | فعلاً `mock` |
| `DEMO_CONTENT` | `fr` (محتوای نمونه فرانسوی برای امتحان اپ زبان‌آموز؛ با شماره ادمین هم دیده می‌شود) |

نکته‌ها:

- **`NODE_ENV` را نگذار.** برنامه خودش آن را درست می‌گذارد.
- اگر رمز پایگاه داده حرفی مثل `@` یا `#` یا `/` دارد، به Claude بگو؛ باید شکل دیگری نوشته شود.
- با `mock` پیامک واقعی نمی‌رود و کد ورود زیر کادر نشان داده می‌شود. برای همین `SITE_PASSWORD` لازم
  است تا کسی جز ما وارد نشود.

## مرحله ۴: دیسک صدا

در سرویس برنامه یک دیسک بساز (۵ گیگ برای شروع کافی است) و مسیرش را این بگذار:

```
/app/storage
```

## مرحله ۵: ساخت و امتحان

1. ساخت (Deploy) را بزن. بار اول چند دقیقه طول می‌کشد.
2. آدرسی را که رانفلر برای برنامه می‌دهد باز کن. مرورگر رمز می‌خواهد: نام کاربری هر چیزی باشد، رمز همان
   `SITE_PASSWORD` است.
3. صفحه ورود باز می‌شود. شماره خودت را بزن، روی کد آزمایشی بزن، باید به «میز کار» برسی.
4. برای اطمینان از سلامت، آدرس برنامه به‌علاوه `/api/health` باید `{"ok":true}` نشان دهد. اگر رانفلر
   جایی برای «بررسی سلامت» (Health check) دارد، همین مسیر را بده.

## بعداً

- **دامنه**: آدرس رایگان رانفلر از داخل ایران باز نمی‌شود. هر وقت دامنه خودمان آماده شد، به سرویس وصلش
  می‌کنیم.
- **پیامک واقعی (کاوه‌نگار)**: وقتی کلید API و نام الگو آماده شد، این سه متغیر عوض یا اضافه می‌شود:
  `SMS_PROVIDER` = `kavenegar`، `SMS_API_KEY` = کلید API، `SMS_TEMPLATE` = نام الگوی تأیید. الگو در پنل
  کاوه‌نگار باید فقط یک `%token` داشته باشد، مثلاً: «کد ورود polyra: %token». اگر در پنل کاوه‌نگار
  «محدودیت IP» روشن است، IP خروجی رانفلر باید اضافه شود.
